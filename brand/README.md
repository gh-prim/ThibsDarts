# Logo ThibsDarts

- `logo-source.jpeg` : dessin d'origine (tête aux lunettes spirale, fond noir).
- `wordmark.svg` : le mot ThibsDarts (Nunito, repris de l'ancien logo).
- `generate.py` : produit tous les visuels (Pi, macOS, iPhone, Apple TV).

Pour mettre à jour : remplacer `logo-source.jpeg` puis `python3 brand/generate.py` (Pillow + cairosvg).
