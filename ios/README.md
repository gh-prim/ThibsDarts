# App iOS ThibsDarts

SwiftUI, iOS 17+. Le projet Xcode est généré par XcodeGen :

```sh
brew install xcodegen
cd ios && xcodegen generate
open ThibsDarts.xcodeproj
```

Pour l'instant : installation du premier allumage (QR code du Pi, Wi-Fi, profil avec vraie photo).
Sur le simulateur, "Taper le code à la main" trouve le Pi qui tourne sur le Mac (`flutter run -d macos` dans `hub/`).
